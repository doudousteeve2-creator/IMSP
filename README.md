# IMSP — Espace Prépa 1

Site HTML statique. La page d’accueil est `index.html`.

## Publication sur Vercel
1. Décompresse `IMSP-site-github.zip`.
2. Ouvre le dossier `IMSP-site` et dépose **son contenu** à la racine du dépôt GitHub connecté à Vercel.
3. Vérifie que `index.html` est au même niveau que les quatre autres pages HTML.
4. Dans Vercel, garde le preset `Other` et laisse Build Command, Output Directory et Install Command vides.
5. Enregistre/commit les fichiers sur GitHub : Vercel relancera automatiquement le déploiement.

Aucun framework ni commande de compilation n’est nécessaire. MathJax et les polices web des fiches nécessitent une connexion Internet.
